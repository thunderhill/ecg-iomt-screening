# ESP32 ECG logger firmware (IoMT sensing device)

Arduino-framework firmware that samples an AD8232 and streams batches to the laptop
gateway over WebSocket secured with TLS (`wss://`). It verifies the gateway certificate
against the project CA and authenticates with its own device token. The wire format is in `docs/protocol.md`, and wiring is
in `docs/wiring.md`.

## Files

- `esp32_ecg_logger.ino`: sampler task, bounded queue, WebSocket client,
  reconnection with backoff, diagnostics.
- `config.example.h`: template. Copy to `config.h` and fill it in, including the device
  token from `scripts/security_setup.py add-device`.
- `ca_cert.h`: generated by `scripts/security_setup.py init`. It holds the CA certificate
  the device trusts. It is git-ignored and never contains a private key.

## Build requirements

- arduino-esp32 core 3.x
- WebSockets library by Links2004 (`WebSocketsClient`)

## Status

**Not compiled for the ESP32 or flashed in this repository.** No board or ESP32
toolchain was available. The sketch was only syntax- and type-checked with
`g++ -fsyntax-only -Wall -Wextra -Wformat=2` against minimal stub headers for the
Arduino, FreeRTOS, WiFi and WebSockets APIs, which catches typos and format-string
errors but nothing about real timing or hardware behaviour. Before relying on it, confirm on your own board:
the achieved sample rate, the ADC readings against a known signal, Wi-Fi
reconnection, and that `dropped` stays at zero.

## Behaviour

- Samples are taken by a periodic task on core 1. Batches of 10 are placed on a
  bounded queue. If the queue is full, the batch is dropped and counted, and the
  sampler is never blocked.
- Network sends happen on the main loop. Reconnection uses exponential backoff,
  from 1 s up to 30 s.
- Before the first connection, the clock is set over SNTP, because TLS checks the
  certificate's validity dates.
- Security notes: anyone holding the board can read the Wi-Fi password and token from
  flash unless ESP32 flash encryption is enabled. Revoke a lost device's token with
  `scripts/security_setup.py revoke-device <id>`.
- A keep-alive is sent every 2 s when there is no sample traffic.
